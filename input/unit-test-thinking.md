　# 単体テストの考え方を掴む

## この記事で書きたいこと（メモ）

- なぜ、テストを行うのか？
  テストがないとソフトウェアは時間の経過とともに停滞していく。
  だけど、単にテストを書いても効果は薄く、良いテストを行うことで停滞を防ぐことができる。

- 良い単体テストを知る
  テストコードもコードと同様書けば書くほど負債になる。
  そのため、テストコードを書く際にはテストの価値と維持コストの両方を考慮する必要がある。

価値のあるテストはドメインにおける重要な部分を検証しているものになる。
ドメインを守ることは品質を担保することに直結するから。
