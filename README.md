# こんにちは 👋

プロダクトを考えたり、作ったりするのが好きです。

普段の仕事ではフロントエンドを中心に開発していて、React / TypeScriptをよく使っています。  
最近は、できることの幅を広げるためにBackendやDatabaseについても勉強しています。

## プロダクト

### カエスネ

家族のお金の立替・精算を管理するために個人で開発しているWebアプリです。
実際に家族で使いながら、身近な課題をもとに改善を続けています。

[kaesune](https://github.com/mda38/kaesune)

### クロモジ

買い物リストを売り場ごとに整理して、店内を効率よく回るために個人で開発しているWebアプリです。  
実際の買い物で使いながら、使いやすさや操作性を改善しています。

[kuromoji](https://github.com/mda38/kuromoji)
