このリポジトリでは以下を管理します。

- 記事

記事では仮説と検証を行いそのレポートを記述します。

① 仮説（問い）

👉 こうじゃない？

② 検証（具体）

👉 実際にやってみた / 調べた

③ 結果（事実）

👉 どうなったか

④ 抽象化（まとめ）

👉 だから何が言えるのか（1行程度）


issueに書くこと
```md
## 仮説

useEffect は描画後に実行されるはず

## 検証したいこと

- render と effect の実行順を確認したい
- state 更新時も同じか確認したい
```

記事の構成テンプレ
```md
<!-- 仮説（問い） -->
## 仮説

<!-- 検証（具体） -->
## 検証
### 1.xx
### 2.xx

<!-- 検証結果（事実） -->
## 検証結果

<!-- 抽象化 -->
## まとめ
```
